# M9 · Marketing site

> Size: M · Depends on: M0, M1

## Goal

Build the public-facing marketing site at the apex domain `transformmynotes.com` (the existing `packages/marketing` Next.js App Router package, port 3000). The site tells the TransformMyNotes brand story — handwriting transformed into clean, highlighted, searchable notes — using the design system tokens and logo assets from `.design/`. It gate-keeps access via an invite/approval model and drives qualified visitors to the app at `app.transformmynotes.com`.

The marketing site has no auth, no DynamoDB access, and no contact form — it has no server-side form handlers. Visitors request access via the primary CTA, which links to the app's sign-up/login. No new `sst.Secret` entries are required for this milestone.

## In scope

- Hero section: brand headline + subhead, `--gradient-transform` squircle mark, animated "handwriting → clean highlighted note" visual motif, primary CTA button ("Request access" → `app.transformmynotes.com/signup`) and secondary link ("Sign in" → `app.transformmynotes.com/login`)
- Feature / benefit sections: Capture (scan your handwriting), Transform (Bedrock Claude OCR to clean Markdown), Search (full-text across all notes), Review (spaced-repetition deck), Groups (invite-gated sharing) — each with a Lucide icon, one-sentence benefit, and the warm-paper card treatment
- "How it works" three-step narrative section (Snap → Transform → Study)
- "Request access" call-to-action strip with a primary CTA button linking to the app sign-up/login (`app.transformmynotes.com/signup`) — no on-site form
- SEO and social: `<head>` metadata (`title`, `description`, canonical URL), Open Graph tags (`og:title`, `og:description`, `og:image` using a static OG card that embeds the logo), `robots.txt`, `sitemap.xml`
- Favicon: SVG favicon and `apple-touch-icon` derived from `logo-mark.svg` (the gradient squircle)
- Responsive, mobile-first layout: single-column stack on narrow viewports; two-column hero + card grid on tablet and up
- Design system fidelity: all colors from `tokens/colors.css`, typography from `tokens/typography.css` (Newsreader serif for display/reading, Hanken Grotesk for UI chrome, Caveat for the "your notes" handwriting accent in the hero), spacing from `tokens/spacing.css`, effects from `tokens/effects.css`
- Committed marketing Playwright E2E suite (`npm run test:e2e`, `e2e/` directory, `playwright.config.ts`) covering: landing page renders with correct headline and CTA, logo/favicon present, no console errors — runs fully offline in CI
- Accessibility: WCAG AA contrast on all text, visible focus rings (`--focus-ring` token), `alt` text on all images, `prefers-reduced-motion` respected
- Page-level analytics stub: a `<Script>` placeholder comment where a script tag would go so adding analytics later is one-line
- Reuse of any shared UI primitives (Button) established in M1 where they exist in the marketing package; do not import from `packages/core` or `packages/application`

## Out of scope

- Auth, DynamoDB, or Cognito of any kind in the marketing package
- Actual invite/approval management UI (that lives in the admin panel, M4)
- A blog, pricing page, or docs section
- Video or animated GIF assets (the brand story is told with CSS/SVG only)
- Real analytics integration (placeholder comment only)
- i18n / multi-language copy (the site is English-only for launch)
- Self-hosted fonts — Google Fonts CDN `@import` in `tokens/fonts.css` is accepted for now per the design system caveat; a future chore can convert to `next/font`

## Architecture & decisions

### Infra
- No new SST resources. `infra/marketing.ts` already attaches `packages/marketing` at the apex via the shared `sst.aws.Router` defined in `infra/router.ts`. `WEB_DOMAIN` is already declared in `infra/secrets.ts` and used for the apex custom domain; the marketing site needs no other secrets (no contact form).
- `CLOUDFLARE_API_TOKEN` remains a Console environment variable (not an `sst.Secret`) as documented in CLAUDE.md.
- PR-stage deployments use auto-generated CloudFront URLs (no apex DNS for ephemeral stages).

### CI/CD
- The existing `npm run test:e2e` gate in `deploy.yml` already runs the marketing Playwright suite; this milestone fills it with real tests. No workflow changes needed.
- Offline CI: `playwright.config.ts` must start the marketing dev server (`next dev -p 3000`) before the tests run; no AWS.

### Design system reference
- **Logo mark** (`assets/logo-mark.svg`): a 96×96 gradient squircle (`rx=26`) holding a page with the signature "handwriting line resolves into clean highlighted text" story. Use inline SVG in the `<header>` so it is accessible (`role="img" aria-label="TransformMyNotes"`) and renders without a network request.
- **Logo wordmark** (`assets/logo-wordmark.svg`): Newsreader serif "Transform" + teal "My" + "Notes" lockup with the mark. Use for hero prominence; use the mark alone in a compact nav bar.
- **Gradient**: `--gradient-transform` (stormy teal `#16747e` → sea green → lime moss → gold `#ffd700`, 105deg) applied to the logo squircle background and optionally as a thin decorative bar at the very top of the hero.
- **Hero display text**: `--font-serif` (Newsreader), `--text-4xl`/`--text-5xl`, `--leading-tight`, `--tracking-tight`, `--text-strong` (`#211e17`).
- **Hero subhead + body**: `--font-sans` (Hanken Grotesk), `--text-md`/`--text-lg`, `--text-body`.
- **Handwriting accent** in hero: a short phrase like *"your notes, transformed"* in `--font-hand` (Caveat), `--text-2xl`, `--text-muted`, with a faint notebook ruling (repeating-linear-gradient) behind it.
- **CTA button**: pill-shaped (`--radius-pill`), `--brand` background, `--on-brand` text, hover → `--brand-hover`, press → scale(0.97) `--brand-press`, `--dur-base` transition.
- **Feature cards**: `--surface-card` (`#fffdf8`) background, 1px `--border-subtle` border, `--shadow-sm`, `--radius-lg` (16px), 20px padding, hover lifts 2px + `--shadow-md`.
- **Highlighter motif**: use `--highlighter` (`rgba(255,215,0,0.38)`) on one key word in the hero headline (e.g. "transformed") via a `<mark>` or `<span>` with a `background` + `border-radius:2px` so it reads as a gold highlighter stroke.
- **Surfaces**: page background `--surface-app` (`#f5f1e8`, warm ivory); sections alternate between `--surface-app` and `--surface-card`.
- **Motion**: all transitions use `--ease-soft` (`cubic-bezier(.32,.72,.26,1)`); hero highlight can animate a `background-size` sweep left-to-right on load. All motion behind `@media (prefers-reduced-motion: no-preference)`.

### A11y
- Minimum contrast ratio 4.5:1 for body text (`--text-body` on `--surface-app` passes); decorative gradient elements exempt.
- All interactive elements: visible `:focus-visible` outline using `--focus-ring` box-shadow token; no `outline: none` without a replacement.
- Semantic HTML: `<header>`, `<main>`, `<section>`, `<footer>`; one `<h1>` per page; logical heading hierarchy.

## Sub-issues (granular tasks)

**1. (S) Page shell, design tokens, and font loading**
Wire the design system CSS tokens into `packages/marketing`: copy `tokens/*.css` as local design token files (or import the design system styles), configure `next/font` with the four font families (Newsreader, Hanken Grotesk, Caveat, Spline Sans Mono) loaded from Google Fonts via `next/font/google`, set global CSS variables on `:root`, and set `--surface-app` as the `<body>` background. Add `favicon.svg` (inlined from `logo-mark.svg`) and `apple-touch-icon.png` to `public/`. Verify with `npm run typecheck && npm run lint` and a quick `npm run dev:marketing` smoke-test.

Acceptance criteria:
- `npm run dev:marketing` loads `localhost:3000` with warm ivory (`#f5f1e8`) background and Newsreader serif rendering on placeholder heading text.
- Favicon tab shows the gradient squircle in Chromium.
- No TypeScript errors, no ESLint warnings.

---

**2. (M) Hero section**
Implement the full hero: inline `logo-mark.svg` in `<header>` nav (with the gradient background, accessible `role="img" aria-label`), a large Newsreader display headline with one word highlighted via `--highlighter` (gold `rgba(255,215,0,0.38)` background sweep), a Caveat handwriting accent line, a one-paragraph subhead in Hanken Grotesk, and two pill CTA buttons ("Request access" → `app.transformmynotes.com/signup` and "Sign in" → `app.transformmynotes.com/login` — both `<a>` tags, not `<button>`, for correct SEO/semantics). On mobile: single-column stack. On tablet+: two-column with a stylized SVG/CSS "notebook page" illustration on the right (CSS-only: warm paper card, notebook ruling lines, Caveat-font "handwriting" lines fading into clean teal-ruled lines).

Acceptance criteria:
- On a 390px viewport the hero stacks cleanly with no horizontal overflow.
- On a 768px+ viewport the two-column layout renders with the illustration on the right.
- The gold highlighter sweep animates on first load; animation is absent when `prefers-reduced-motion: reduce`.
- Both CTAs are `<a href>` elements that link to `app.transformmynotes.com`; they open in the same tab (no `target="_blank"`).
- Lighthouse accessibility score ≥ 90 on the hero section alone.

---

**3. (S) Feature / benefit section**
Six feature cards in a responsive grid (1 col mobile, 2 col tablet, 3 col desktop): Capture, Transform, Search, Review, Groups, and Invite-gated access. Each card: Lucide icon (24px, `--brand` teal color), a short bold title in Hanken Grotesk semibold, a one-sentence benefit in `--text-body`, `--surface-card` background with `--shadow-sm` and `--border-subtle`. Hover: lift 2px + `--shadow-md` + `transition: var(--dur-base) var(--ease-soft)`. No links — purely informational.

Acceptance criteria:
- Cards display in a 3-column grid at 1040px+ and collapse to 1-column at <480px.
- All Lucide icons render as inline SVG (not an `<img>` tag), carry `aria-hidden="true"` since the card title is the label.
- Hover lift animation respects `prefers-reduced-motion`.

**4. (S) "How it works" three-step section**
A numbered step sequence: 1 — Snap (photograph your handwritten page with your phone camera), 2 — Transform (Bedrock Claude reads the handwriting and produces clean, highlighted Markdown), 3 — Study (search, review, and share in invite-gated groups). Each step: large mono step number in `--font-mono` `--text-5xl` teal, short title in Newsreader, one-sentence description in Hanken Grotesk. Laid out as a horizontal stepper on tablet+ and a vertical stacked list on mobile. A thin `--gradient-transform` line connects the steps as a decorative HR on wide viewports.

Acceptance criteria:
- Step numbers read as decorative (wrapped in `aria-hidden="true"` `<span>`); section has an `<h2>` heading "How it works".
- Gradient connector line is hidden from screen readers (`aria-hidden="true"` or CSS-only pseudo-element).
- No horizontal overflow at 320px viewport width.

## Risks / open questions

- **Google Fonts CDN in CI**: `playwright.config.ts`'s offline CI mode may result in font-fallback rendering; tests must not assert on specific font-family rendering, only on structural elements. A future `next/font` migration (self-hosted) would fully resolve this.
- **OG image**: a static PNG is simplest; if a dynamic `/api/og` route using `@vercel/og` is preferred later, it can be added in a follow-up — do not block M9 on it.
- **`app.transformmynotes.com` not yet live on M9**: the marketing CTA links hardcode `app.transformmynotes.com`. If M9 is deployed before the app subdomain is live (M10 DNS cutover), links will 404. Consider using a `/coming-soon` stub or adding an `[skip deploy]` escape on early M9 PRs.
- **Open question**: should the marketing nav include a "Sign in" link in the header at all times, or only on scroll past the hero? Decision needed before sub-issue 2 is implemented.

## Manual test plan

2. **Desktop layout** — widen to 1200px. Expected: hero becomes two-column (text left, CSS notebook illustration right), feature cards display in a 3-column grid.
3. **CTA links** — click "Request access". Expected: navigates to `app.transformmynotes.com/signup`. Click "Sign in". Expected: navigates to `app.transformmynotes.com/login`. Both open in the same tab.
4. **Favicon and OG** — observe the browser tab favicon (gradient squircle). In a new tab open `https://transformmynotes.com/og-image.png`. Expected: 1200×630 image with the wordmark on warm ivory.
